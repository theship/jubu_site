        <h2>An agent with a vision <strong>performs better</strong></h2>
        <p>Everything valuable in an organization begins as leadership vision, and realizing it generates data objects everywhere: specs, code, pipelines, CRM records, support threads. Almost none of those objects were designed to carry the vision that produced them, so they drift: the same entity named three ways, definitions current in one system and stale in another, reasoning that lives in someone's head while the object records only the steps.
        </p>
        <p>Humans absorb that drift with judgment. Agents can't. They act on the objects literally, at scale, and carry every ambiguity into every task downstream. The distance between what leadership means and what the objects say is the <strong>vision gap</strong>. Closing it is architecture work, not transcription work.
        </p>
        <p><em>The AI acts on what you give it. Whatever your data does not say clearly, the AI will say for you.</em>
        </p>

        <h2>Agent-readiness is a <strong>vision-fidelity problem</strong>, not a documentation problem</h2>
        <p>An agent-ready organization is built in process order: first the substrate agents read, then three decisions about how the work is organized, then the loop that proves the rest is working. Six layers, seven tests. Every test runs in-house, with the tools and access you already have.
        </p>
        <ul>
          <li><strong>The legible substrate</strong>, covering vision &amp; principles and vocabulary &amp; contracts. Tested by <code>tradeoff-probe</code> and <code>ten-term-diff</code></li>
          <li><strong>The knowledge graph as domain bounds</strong>, an explicit, versioned domain model wired in as the boundary of agent investigation. Tested by <code>traversal-probe</code></li>
          <li><strong>The deterministic boundary</strong>, separating tested machinery from model judgment. Tested by <code>misallocation-inventory</code></li>
          <li><strong>Workflows from observation, not the org chart</strong>, tested by <code>cold-start-run</code></li>
          <li><strong>A single owner of judgment</strong>, tested by <code>coherence-probe</code></li>
          <li><strong>Evals &amp; feedback</strong>, tested by <code>silent-failure-probe</code></li>
        </ul>

      <figcaption class="md-typeset">
        <h2>The framework, <strong>built</strong></h2>
        <p>Towndraft is an agentic pipeline on FastAPI, Next.js, and Supabase with pgvector. Five stages run in sequence: staged retrieval, verified web research, knowledge-graph extraction and merge, ontology-typed gap-filling, and drafting.
        </p>
        <p>The point worth making explicitly: the agents work from a versioned, entity-resolved knowledge graph, not from raw prompts. The graph is not one stage among five. It is the substrate every stage reads from and writes to. That is layer 02 of the field guide, shipped.
        </p>
        <p><em>A framework nobody has built is a thesis. A framework running in production is a practice.</em>

      <figcaption class="md-typeset">
        <h2>Agent-ready is <strong>measurable</strong>, not aspirational</h2>
        <p>Spec-driven development runs as standard practice: a project constitution agents read on every task, vertical-slice specs with acceptance criteria, and evals from the first agent run rather than after the first incident.
        </p>
        <ul>
          <li>A platform-neutral framework for agent-assisted code review, with capability-scoped agent charters, phase playbooks with explicit entry and exit criteria, and CI checks that block drift between spec and enforcement</li>
          <li>Prompt versioning and per-stage cost, latency, and degradation telemetry through W&amp;B Weave</li>
          <li>Outcome and trajectory evals, so a regression is caught by instrumentation rather than by a user</li>
        </ul>
        <p>Every stage is observable, every claim is checkable, and the interface surfaces its own progress and confidence rather than presenting a finished answer with no provenance.
        </p>
